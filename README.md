# 卷尺定制图案设计器

在线设计可印刷到卷尺盘面（圆形端盖）上的定制图案：文字 + 照片 + 水印 Logo 合成预览，一键导出高清 PNG 交付印刷。

纯前端实现，**零依赖、零构建**，双击 `index.html` 即可使用，也可直接部署到任意静态托管。

界面采用 **LASER MARKING 激光打标工业化风格**：单色调、细线条边框、点阵式底纹、等宽字体、条形码与序列号铭牌，整体呈精密仪器的视觉感受。

## 功能

- **文字排版**：姓名 / 祝福语 / 日期 / 电话 / 品牌名等内容，可调字体、字号、字重、字间距、颜色、对齐方式
- **雕刻质感**：浮雕（雕刻感）、柔光、描边、投影等效果，模拟印刷后的镭雕/丝印观感
- **弧形排布**：文字可沿盘面圆周环绕，适合做环绕式品牌字
- **照片处理**：上传本地照片，支持缩放、旋转、圆形/圆角方/直角方裁剪，以及亮度、对比度、饱和度、单色化调色
- **水印素材**：内置 8 款矢量 Logo（五角星、太阳飞翼、几何标、皇冠、徽章盾等），可自由摆放缩放
- **所见即所得**：盘面实时预览，可选开/关卷尺外壳效果（仅用于预览，不参与导出）
- **高清导出**：1200 / 2400 / 3600 px 三档（对应 58mm @ 300 / 600 / 900 DPI），支持含底色 / 白底 / 透明底
- **示例模板**：6 套现成版面，点击即用，改字即可出货
- **响应式**：桌面端三栏布局，移动端自动堆叠，支持手势缩放
- **打印参数铭牌**：右栏底部常驻 MODEL / DIA / SAFE / DPI / COLOR / MATERIAL 参数表与序列号

## 使用方法

1. 浏览器打开 `index.html`
2. 左栏「示例模板」选一套开局，或从空白开始
3. 「快速加文字」加姓名/电话/日期/祝福语；「上传本地照片」加头像或门店图
4. 在画布上**点选**元素 → 右侧调整属性；**直接拖动**摆位置；**双击文字**就地修改
5. 右下选择导出尺寸与背景 → 「导出高清图片」

## 印刷尺寸说明

- 画布逻辑坐标系 1000×1000，盘面直径按 **58mm** 计（`r=500` 即 29mm）
- 辅助线标出**安全区（φ55mm）**，重要内容请留在安全区内，靠边内容裁切时可能被切掉
- 导出为方形画布、圆形盘面居中已裁切；印刷时按盘面实际直径等比对应即可
- 默认 300 DPI 用 1200px；需要更精细的丝印细节可导出 2400 px
- 三种导出背景的用途：
  - **含盘面底色** —— 直接交付印刷的正稿
  - **白底** —— 需印在白卡纸/白底材质上时看效果
  - **透明底** —— 只要图案不要底，用于抠图、拼版或后续套色

## 文件结构

```
index.html    页面骨架与面板
styles.css    样式（激光打标工业化主题 + 响应式断点）
app.js        全部逻辑：数据模型 / 绘制 / 交互 / 导出
```

## 技术要点

- 元素坐标为逻辑单位（0..1000），导出任意尺寸只需整体缩放，保证不同 DPI 下版式一致
- 命中检测走**离屏彩色图层**方案：每个元素用唯一颜色绘制到隐藏画布，读取像素反查元素 ID，因此旋转文字、弧形文字、圆形裁剪图片都能精确点选
- 弧形排布半径按 `r = 字串总宽 / 弧跨度(弧度)` 反推，并夹在「单字不重叠」与「弧顶不出盘面」之间，角度变化时版式自动收敛
- 所有素材（Logo、照片占位图）均为内联 SVG / DataURI，无外部请求，可离线使用
- 全站视觉为纯 CSS 实现：点阵底纹用 `radial-gradient` + `background-size`，条形码用不等宽 `repeating-linear-gradient`，未引入任何图片资源

## 部署

纯静态，无构建步骤：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

或将三个文件直接放进任意静态托管（GitHub Pages / Cloudflare Pages / Nginx）。
